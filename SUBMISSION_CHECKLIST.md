# Before submission checklist

- [ ] Run the app successfully on your own laptop.
- [ ] Ask at least one normal factual question.
- [ ] Ask a question requiring two documents.
- [ ] Compare old and current policy rules.
- [ ] Ask a question whose answer is missing.
- [ ] Run both prompt-injection tests.
- [ ] Run six retrieval questions at k=1, 3, 5.
- [ ] Change chunk size or overlap and repeat three questions.
- [ ] Fill all 20 actual test outcomes in the CSV.
- [ ] Write real measured findings and failures in the report.
- [ ] Record a 3–5 minute demo and add its link to README.
- [ ] Remove `.env`, `.venv`, caches, and API keys before ZIP submission.
